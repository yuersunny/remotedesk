# RemoteDesk 使用说明书

**版本 1.0.8** · 适用于 macOS 13+ / Windows 10 1809+ / Android 7.0+

这份说明写给"拿到安装包、只想把它用起来"的人。不需要懂编程，不需要买服务器，也不需要注册任何账号。

---

## 1. 三分钟上手

最常见的情况：**一台 Mac 放在家里或办公室，你想从另一台电脑或手机上操作它。**

按顺序做这四步：

| 步骤 | 在这台机器上做 | 在另一台机器上做 |
|---|---|---|
| 1 | 装 RemoteDesk，打开 | 装 RemoteDesk，打开 |
| 2 | macOS：给「屏幕录制」「辅助功能」两个权限，然后**退出重开** | — |
| 3 | 两台连同一个 Wi-Fi | 两台连同一个 Wi-Fi |
| 4 | 对方的名字会出现在「连接另一台电脑」列表里，点一下 | 被控那台弹窗，点「接受并共享屏幕」 |

连上以后，你看到的就是对方桌面，鼠标键盘直接可用。

> **提示**：列表里没有对方，不是软件坏了，八成是两台不在同一个网络里。直接跳到第 4 章看「配对码」，一行字就能连，不需要在同一个 Wi-Fi。

**三句话记住这个软件：**

1. 每台机器自己就是服务器，**没有中心服务器要你注册**。
2. 连接靠一行「配对码」，里面已经包含地址、名字和密码。
3. 跨网络不用配路由器，两端装 Tailscale、登同一个账号就行。

## 2. 先认清三件事

### 2.1 谁被控、谁主控

| 角色 | 意思 | 谁来做 |
|---|---|---|
| **被控端** | 屏幕被看、鼠标键盘被操作的那台 | Mac / Windows 桌面 |
| **主控端** | 看着画面、动手操作的那台 | Mac / Windows / 安卓手机 |

同一台机器可以随时切换角色，也可以同时是两者（一边被人看，一边去看别人）。

### 2.2 能做什么

- 看对方整个屏幕，实时画面（默认 60 fps，可调 30）
- 用自己这边的鼠标键盘操作对方电脑
- 双向纯文本剪贴板：这边复制，那边直接粘贴
- 手机当主控：单指点击、长按右键、双指滚动、捏合放大
- **一台被控、多台同时看**：第二个人直接连进来，不用等前面的人下线；被控端看得到谁在连，可逐个「断开」
- 无人值守：对方电脑没人也能连（需要密码）

### 2.3 不能做什么（先看清楚，省得白折腾）

| 做不到 | 原因 |
|---|---|
| **手机屏幕共享给别人看** | 这一版手机只做主控。共享手机屏幕要录屏授权 + 常驻前台服务，是另一件事 |
| **打中文、打表情到对面** | 输入通道传的是"按了哪个键"，不是文字。要打中文，在**被控那台**切中文输入法 |
| 传文件、拖拽文件 | 没有做 |
| 多显示器切换 | 只采集主屏 |
| 断线自动重连 | 断了要手动再连一次 |
| 控制以管理员身份运行的窗口（Windows） | 系统限制（UIPI 隔离），任何远程软件都一样 |
| 看到对方鼠标形状变化（文本竖线、拉边框的双箭头） | 只画一个箭头光标，但点击位置是准的 |

## 3. 安装

### 3.1 macOS

1. 双击 `RemoteDesk-1.0.8-macos-universal.dmg`
2. 把 RemoteDesk 拖进「应用程序」
3. 打开它。第一次会被系统拦下来，提示"无法验证开发者"：**右键点图标 → 打开 → 再点一次「打开」**，之后不再问
4. 如果提示"已损坏，无法打开"，打开「终端」，粘这一行回车：

```
xattr -dr com.apple.quarantine /Applications/RemoteDesk.app
```

这个包是通用二进制，Intel 和 Apple Silicon（M 系列）都能跑。

### 3.2 Windows

Windows **没有预编译的 exe**（项目在 Mac 上开发，Flutter 不能交叉编译到 Windows）。两条路，先试第一条：

**A. 浏览器版，双击就能用（只能当主控）**

打开 `installers\windows\`，双击 `00-RUN-WEB-NOW.cmd`。会弹一个黑色命令行窗口，然后自动打开浏览器。

- 这个黑窗口就是服务本身，**用的时候别关**，关掉服务就停了。
- 只能操作别人，别人看不到也操作不了这台机器。
- 页面必须开在 `localhost`，别用 `192.168.x.x:8080` 打开，否则拿不到画面（浏览器安全限制）。

**B. 编译一个原生 exe（一次 20 分钟，之后和普通软件一样）**

同一个目录里按顺序双击：

| 顺序 | 文件 | 干什么 |
|---|---|---|
| 1 | `01-check-env.cmd` | 体检，只读不改，看缺什么 |
| 2 | `01b-enable-dev-mode.cmd` | 打开「开发者模式」 |
| 3 | `03-install-vs-buildtools.cmd` | 装 Visual Studio Build Tools（10–20 分钟） |
| 4 | `02-install-flutter.cmd` | 装 Flutter SDK（5–10 分钟） |
| 5 | `04-build-windows.cmd` | 编译（3–8 分钟） |
| 6 | `05-run-windows-app.cmd` | 启动 |

第 3、4 步装完要**关掉窗口重开**，环境变量才生效。编译出来的 `Release\` 整个文件夹就是绿色版，拷到别的 Windows 机器上也能直接跑。

### 3.3 Android

1. 把 `RemoteDesk-1.0.8-android-arm64.apk` 传到手机（微信文件传输助手、数据线、网盘都行）
2. 点开安装，系统会拦一次，允许「未知来源」
3. 装完直接打开

要求 Android 7.0 以上，且是 arm64 机型（2017 年以后的手机基本都是）。手机只申请网络权限，没有录屏授权弹窗，也没有常驻通知。

### 3.4 装完必须先做的权限（macOS 绕不过）

被控端要采集屏幕、要模拟鼠标键盘，这两件事 macOS 强制要求你手动点允许：

| 权限 | 在哪开 | 不开会怎样 |
|---|---|---|
| 屏幕录制 | 系统设置 → 隐私与安全性 → 屏幕录制 → 勾 RemoteDesk | 对方看到**黑屏** |
| 辅助功能 | 系统设置 → 隐私与安全性 → 辅助功能 → 勾 RemoteDesk | 画面正常，但**鼠标键盘点了没反应** |
| 本地网络 | 首次运行弹窗，点允许 | 自动发现找不到设备（用配对码仍可连） |

> **注意**：改完权限必须**退出 App 再重开**才生效。macOS 只在启动时读这些授权，不重开的话你会以为权限没给对。

Windows 首次运行会弹防火墙，勾「专用网络」并允许。不允许的话对方连不上 8787 端口。

## 4. IP、端口与"注册"——这一章解决大部分困惑

### 4.1 先说不用做的

很多人一上来会问"IP 在哪注册""要不要买个服务器""要不要备案"。**都不需要。**

| 你担心的 | 实际情况 |
|---|---|
| 注册账号 | 不用。没有账号系统，没有登录 |
| 买云服务器 | 不用。每台机器自己就是服务器 |
| 域名、备案 | 不用。连接靠 IP 或配对码 |
| 固定公网 IP | 不用。局域网用内网 IP，跨网用 Tailscale 的 100.x 地址 |
| 端口映射、DDNS | 不用。除非你明确要"不装任何软件从公网直连"，那属于高级用法，见 4.9 |

### 4.2 那"注册"到底发生在哪

只有一件事，而且发生在**本机内部**，不对外：

程序一启动，会在自己这台机器上起一个小服务，监听 **8787** 端口，然后把自己"登记"上去——登记的内容是**设备名**（比如 `mac-mini`）和一个会话标识。别的主机来问"你是谁、8787 通不通"，它就报出自己的名字。

```
   your Mac                                  peer machine
 +---------------------+             +---------------------+
 |  RemoteDesk         |             |  RemoteDesk         |
 |  local service 8787 |<-- hello -->|  sees you in list   |
 |  name  mac-mini     |             |  click to connect   |
 |  udp 8789  beacon   |-- i am here>|                     |
 +---------------------+             +---------------------+
             |                                   |
             +------ screen / mouse / keys ------+
                 (WebRTC, DTLS-SRTP encrypted)
```

左边是"被控端"，右边是"主控端"：8787 只负责打招呼，打完招呼画面和鼠标键盘就在两台机器之间直连，不再经过任何第三方。

所以"注册 IP"这个说法在这个软件里不存在。**你唯一需要提供的，是让对方能访问到你的地址**——也就是下面这些 IP。

### 4.3 三种连接方式，什么时候用哪个

| 方式 | 需要你知道什么 | 适用场景 | 成功率 |
|---|---|---|---|
| **自动发现** | 什么都不用 | ① 两台在同一个 Wi-Fi；② 两台都装了 Tailscale 客户端并登录同一账号（列表里会直接出现对方的 `100.x` 地址） | 最高，首选 |
| **配对码** | 一行字，复制粘贴 | 列表里没有对方；不在同一个网；发给别人 | 高，万能 |
| **手动连** | 对方 IP + 对方设备名 + 密码 | 配对码丢了、只想填 IP；或者做排障 | 中，要填对三项 |

**电脑端**两条自动发现都走：局域网 UDP 广播找同 Wi-Fi 的机器，`tailscale status` 找同 tailnet 的机器，结果合并去重（同一台机器两条路都找到时只显示一行）。

**手机端只有局域网这一条**。安卓从系统层面就读不到 Tailscale 的节点列表（那是另一个 App 的进程），所以列表中只会出现同一 Wi-Fi 下的电脑。**人在外面用手机流量，必须用配对码**——这不影响连通性，外面照样连得上，只是要手动粘一次。

### 4.4 界面最上面那条状态条：一句话回答"能不能从外面连"

打开 RemoteDesk，「这台电脑」卡片最上面有一条彩色的行。它回答的正是这个问题——**别人（尤其是人在外面的手机）能不能连到我？**

| 它写什么 | 颜色 | 意思 | 你要做什么 |
|---|---|---|---|
| 出门也能连 | 绿 | 有 Tailscale 地址（`100.x`），家里、公司、手机流量都能连 | 不用做什么，把配对码发给对方 |
| 只能在同一个 Wi-Fi 里连 | 橙 | 只有局域网地址（`192.168.x` / `10.x` / `172.16–31.x`） | 要跨网就装 Tailscale，点右边「怎么连」看三步 |
| 可能能从外面连（要看路由器） | 蓝 | 有公网地址，但要路由器把 8787 转发过来；运营商大内网转发也没用 | 不稳定，建议改走 Tailscale |
| 还没连上网络 | 灰 | 没检测到任何可用地址 | 先确认这台机器连上了网 |

点这一行右边的「怎么连」，会展开一段解释加三步操作。

**橙色状态下展开的就是"要让外面也能连"的三步**：

1. 这台电脑装 Tailscale 并登录（`tailscale.com`，免费）
2. 手机装 Tailscale，登录同一个账号
3. 回来点下面的「重新检测」，状态会变成「出门也能连」

装完 Tailscale 状态没变，先点「重新检测」，别急着重装——状态只在启动时和点这个按钮时读一次，不会自己刷新。

**绿色状态下展开的是"手机在外面怎么连"**：手机装 Tailscale 登同一账号 → 在电脑上复制配对码发到手机 → 手机里粘上点「连接」。

> 为什么要专门做这条状态条：以前"能不能从外面连"要自己进「更多设置」看一个 IP 段来判断，结果是很多人以为这软件只能局域网用。状态条就是把这句话直接摆出来。

### 4.5 怎么查自己的 IP

**macOS**

图形界面：系统设置 → 网络 → 点当前连接（Wi-Fi 或有线）→ 详细信息 → 看「IP 地址」。

命令行（更快，复制走就行）：

```
ipconfig getifaddr en0      # Wi-Fi
ipconfig getifaddr en1      # 有线（部分机型反过来）
```

**Windows**

命令行：

```
ipconfig
```

找当前网卡下面的 `IPv4 地址`，形如 `192.168.1.20`。无线局域网适配器 WLAN 就是 Wi-Fi。

浏览器版还带了个更省事的小工具：在 `installers\windows\` 里打开 PowerShell，跑

```
.\node\node.exe tools\lan-info.mjs
```

它会把本机每张网卡的地址列出来，告诉你该把哪个填给对方。懒得折腾就直接用 `ipconfig`，效果一样。

**Android**

设置 → WLAN → 点当前网络 → 看「IP 地址」。但手机一般只当主控，不需要别人连它。

**Tailscale 的地址**

装了 Tailscale 并登录后，地址是 `100.x.x.x` 开头，在任何网络下都不变。这是跨网络时唯一需要记的地址。

> **提示**：`127.0.0.1` 永远指"这台机器自己"，填它只能连到自己，别把它当成对方地址。看到连接目标里出现 `127.0.0.1` 而对方在另一台机器上，就是填错了。

### 4.6 端口清单

| 端口 | 协议 | 用途 | 要不要管 |
|---|---|---|---|
| 8787 | TCP | 每台机器的握手服务（"注册"就发生在这里） | 防火墙要放行，否则对方连不上 |
| 8789 | UDP | 局域网自动发现广播 | 一般不用管；被拦了就用配对码 |
| 动态高位 | UDP | WebRTC 画面与输入的实际通道 | 系统自动放行 |
| 3478 / 5349 | TCP+UDP | 自建中继（coturn）才用 | 不用自建就不用管 |
| 49152–65535 | UDP | 自建中继的中继端口段 | 同上 |

家用路由器默认不拦出站，入站只拦 8787 就够。公司网络如果连 8787 都不通，别硬扛，直接用 Tailscale。

### 4.7 让 IP 不变：DHCP 保留

内网 IP 是路由器动态分配的，重启路由或过几天可能从 `192.168.1.20` 变成 `.23`，这时你写死在别处的地址就失效了。两种做法，**推荐第一种**：

**做法一：在路由器里做 DHCP 保留（推荐）**

1. 查出这台机器的 MAC 地址
   - macOS：系统设置 → 网络 → 详细信息 → 硬件 → MAC 地址
   - Windows：`ipconfig /all`，看「物理地址」
2. 登录路由器管理页（通常是 `192.168.1.1`，账号密码在路由器背面）
3. 找到「DHCP 静态分配 / 地址保留 / IP-MAC 绑定」
4. 把 MAC 和想要的 IP（比如 `192.168.1.20`）绑一起，保存

好处：IP 固定了，但网关、DNS 这些仍然由路由器自动下发，换网络也不会把机器配坏。

**做法二：在本机设静态 IP（不推荐新手做）**

macOS：系统设置 → 网络 → 详细信息 → TCP/IP → 配置 IPv4 改成「手动」。
Windows：网络适配器 → 属性 → IPv4 → 使用下面的 IP 地址。

必须同时填对**子网掩码**（一般 `255.255.255.0`）、**路由器/网关**（一般 `192.168.1.1`）、**DNS**（`223.5.5.5` 或 `8.8.8.8`）。填错任何一项，这台机器就上不了网，而且看起来像"软件坏了"。

> **注意**：出门带着笔记本换 Wi-Fi 时，静态 IP 会变成上不了网的元凶。所以能用 DHCP 保留就别用静态 IP。

### 4.8 跨网络：用 Tailscale，不要端口映射

两台不在同一个 Wi-Fi（一台在公司、一台在家，或者手机用 4G/5G），最省事的是 Tailscale：

1. 两端都去 `tailscale.com/download` 下载安装
2. 两端登录**同一个账号**（Google / Microsoft / GitHub 账号都行）
3. 装完在 Tailscale 里能看到对方的 `100.x.x.x` 地址
4. 回到 RemoteDesk，配对码里带的就会是 `100.x` 地址，照常用

为什么推荐它：它把两台机器放进一个虚拟局域网，地址固定、加密、不用动路由器。RemoteDesk 的画面本身仍然是两端直连 + 加密，Tailscale 只负责"路能通"。

**不推荐端口映射**：把 8787 直接暴露到公网，等于把一个没有账号体系的服务挂到互联网上，扫描器几分钟就能找到。真要从公网直连，见 4.9 的三条硬要求。

### 4.9 非要从公网直连（高级，风险自担）

必须同时做到三条，缺一条都别开：

1. **信令走 `wss://`**。`ws://` 是明文，密码和会话都在裸奔。需要自己配证书（Let's Encrypt 免费）。
2. **口令不能是 `123456`**，也不能是"公司名 + 123"。程序自动生成的是 6 位随机数，够用；改就改成 8 位以上。
3. **限制来源**。路由器/云防火墙只放行你常用的 IP，别对 `0.0.0.0/0` 开放 8787。

更稳的做法是：**用 Tailscale 或 WireGuard 把信令关在私有网络里**，公网上根本看不到 8787。这也是这个项目推荐的跨网方式。

### 4.10 手动连怎么填

在「连接另一台电脑」卡片最下面，展开「手动连（配对码不好用时）」，有三项：

| 字段 | 填什么 | 例子 |
|---|---|---|
| 对方的名字 | 对方「这台电脑」卡片上显示的那串字 | `mac-mini` |
| 密码 | 对方「连接密码」框里那 6 位数字 | `728491`（示例） |
| 对方地址 | 下面三种写法都认 | `192.168.1.20` |

这一栏平时是折起来的，因为 95% 的情况用配对码一行字就够。它只在你手上只有 IP、或者要逐项确认哪一环不通时才需要。

地址三种写法等价，程序会自动补全：

```
192.168.1.20                 只写 IP，默认端口 8787
192.168.1.20:8787            带端口
ws://192.168.1.20:8787/ws    完整地址
```

> **注意**：三项里「对方的名字」不能空，它不是备注，是握手时要核对的设备 ID。不知道名字就问对方要配对码，别猜。

## 5. 第一次连接

### 5.1 方式一：自动发现（同一个 Wi-Fi）

1. 两台都打开 RemoteDesk，停在主界面
2. 主控端的「连接另一台电脑」里会出现对方的名字，下面小字写着来源和 IP
3. 点那行
4. 第一次连会弹一个密码框：对方开了「允许远程控制」就填它显示的 6 位密码；没开就**留空直接点「连接」**
5. 对方点「接受并共享屏幕」，画面就过来了

### 5.2 方式二：配对码（万能）

被控端「这台电脑」卡片上有一行灰底的字，点一下即复制：

```
RDSK1 100.101.102.103:8787 mac-mini 728491
```

把它发给对方（微信、短信、念出来都行），对方粘进「或者粘贴对方给你的配对码」，点「连」。

这一行里已经包含地址、设备名、密码，不用再填别的。**它不要求两台在同一个网络**，只要能互通就行。

> **注意**：配对码里是**明文密码**。发到群里等于把密码公开了；用完最好点一下密码框旁边的刷新按钮换一个。

### 5.3 方式三：手动连

在「连接另一台电脑」卡片最下面展开「手动连（配对码不好用时）」，填对方名字、密码、地址。字段说明见 4.10。

适合对方没开自动发现、或者你在做排障。

### 5.4 被控端会看到什么

- **没开「允许远程控制」**：屏幕中间弹「收到远程协助请求」，有人点「接受并共享屏幕」才继续。
- **开了「允许远程控制」**：密码对就直接进，本机不需要有人。
- 进入共享后，被控端窗口会提示"正在共享本机屏幕"。**可以最小化，但别关掉**——关掉窗口等于结束共享，对面立刻黑屏。

### 5.5 连上之后先确认三件事

看画面右下角/工具条上的小字：

| 指标 | 正常值 | 不正常说明 |
|---|---|---|
| 分辨率 | 和你屏幕一致或按比例缩小 | 显示 0 或空白 → 采集源没选对 |
| 帧率 | 20–60 fps | 个位数 → 网络差，或在跑大程序 |
| 延迟 | 20–80 ms（同城） | 几百 ms → 走了中继，画面会拖影 |

### 5.6 多台设备同时看同一台电脑

一台被控机可以**同时**给多台设备共享，不用排队、不用等上一个人下线。典型场景：Mac mini 开着共享，你在 Windows 上操作、同事在安卓手机上看同一块屏幕。

被控端「这台电脑」卡片最上面会出现一行绿的：

```
1 台设备正在看这台电脑        （或 2 台、3 台……）
   win-office        [断开]
   pixel-7           [断开]
```

每行后面的「断开」只踢掉那一台，其他不受影响。

三条需要注意：

- **画面只采集一次**。第二个人进来时复用同一条采集流，所以不会出现"人越多越卡"，也不会在 macOS 上第二次弹屏幕录制授权。
- **鼠标键盘会互相抢**。多人同时操作时两边的指针都在动，看不出是谁在动。要稳定操作，就只留一个人——其余的点「断开」，或者让对方用「只看不控」。
- **被控端不开了不会连着断**。你关掉一个人的会话，剩下的人继续看；被控端整体退出程序，所有人才会一起断。

## 6. 连上之后怎么操作

### 6.1 电脑当主控

就是普通鼠标键盘，点哪儿是哪儿。工具条上的按钮：

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| **控制中 / 只看不控** | 临时切断输入转发 | 只想看对方屏幕演示，怕误点 |
| **剪贴板 / 剪贴板关** | 开关跨机剪贴板 | 怕覆盖对方剪贴板时 |
| **推送剪贴板**（图标） | 把本机当前剪贴板立刻发过去 | 连接**之前**复制的内容用这个补发 |
| **挂断** | 结束会话 | — |

几个快捷键的坑：

- macOS 主控 + Windows 被控时，**⌘ 会自动当 Ctrl 发**。所以 ⌘C 到 Windows 上是复制，不会变成 `Win+C` 弹开始菜单。反过来 Windows 主控 + Mac 被控，`Ctrl` 就是 `Ctrl`，不映射成 ⌘。
- `Ctrl+Alt+Del`、`Cmd+Tab`、`Win+L` 这类**系统级组合键不转发**，它们由你本机操作系统截走了，任何远程软件都送不过去。
- 输入法候选框、右键菜单都能正常用，但中文输入要在被控那台切输入法。

### 6.2 手机当主控（安卓）

| 手势 | 效果 |
|---|---|
| 单指点一下 | 左键单击 |
| 单指按住拖 | 按住左键拖动（选文字、拖窗口） |
| 单指长按 | 右键，弹菜单 |
| 双指上下滑 | 滚轮上下滚 |
| 双指捏合 | 放大/缩小画面（只放大手机这边，不改电脑分辨率） |
| 放大后双指拖 | 平移画面 |
| 放大后右下角蓝色「还原」 | 一键回到 100%（放大后才会出现，就在拇指旁边） |
| 右上角方框图标 | 还原画面大小（和上面那个等效） |

顶栏按钮：

- **键盘**：打开软键盘面板。可以直接打字，另有 Ctrl / Alt / Shift / Win 锁定键、Esc / Tab / Enter / ⌫、方向键、Del / Home / End / PgUp / PgDn / F5。
- **更多**：改成「只看不控」、还原画面大小、把手机剪贴板发到电脑、开关剪贴板同步、手势说明。
- **断开**：结束会话。

**连不上、想换一台电脑怎么办**

以前这里只能退出程序重来，现在两条路都在界面上：

| 当前状态 | 屏幕上有什么 | 点了会怎样 |
|---|---|---|
| 还在等（转圈） | 中间「停止等待」 | 立刻取消这次连接，回到电脑列表 |
| 已经失败（显示「没连上」） | 中间「回到电脑列表」 | 同上，并告诉你可能是对方程序没开或没人点接受 |
| 已经连上 | 顶栏最左边的返回箭头 | 断开当前这台 |

两种退出都会先问一句「停止这次连接？」，确认后回到电脑列表——**可以马上连另一台，不用退出 App**。等太久也会自己停：电脑端 25 秒没反应就判为失败，不会一直转。

> **注意**：手机键盘面板只能发英文、数字、符号。打中文没反应是设计限制，不是坏了——要打中文，在电脑上切输入法，或者先用手机复制文字，再用「把手机剪贴板发到电脑」。

## 7. 剪贴板

**双向、纯文本、自动。** 在一端选中按复制，到另一端直接粘，不需要任何操作。

它是这样工作的，遇到"怎么没同步"时按这几条对：

| 规则 | 行为 | 为什么这么设计 |
|---|---|---|
| 连接时不同步已有内容 | 连上那一刻两边剪贴板都不动 | 两边内容几乎总是不一样，一连上就互推等于无声覆盖对方正在准备的东西 |
| 连接前复制的内容 | 不会自动过去，用「推送剪贴板」补发 | 同上 |
| 上限 160 KB | 超了直接丢弃并记日志，**不截断** | 粘一半进输入框比没粘更糟 |
| 只同步纯文本 | 图片、文件、富文本都不过去 | 传文件是另一件事，没做 |
| 自己写入的不回推 | 避免两边来回弹 | 防"乒乓" |
| 换行会归一化 | Windows 的 `\r\n` 和 macOS 的 `\n` 当同一个 | 否则同样的内容会被判成"变了" |

## 8. 无人值守：不用有人在对面守着

默认情况下，每次连接都要被控那台有人点「接受」。想半夜从家里连办公室的机器，就把开关打开：

1. 被控端「这台电脑」卡片 → 打开「允许远程控制」
2. 程序会自动生成一个 **6 位数字密码**（没有就点旁边的刷新按钮生成）
3. 把「设备名 + 密码」发给对方，或者直接发整行配对码
4. 对方连的时候输密码，正确就直接进

密码规则：

- 6 位随机数字，用系统安全随机源生成，不是按时间猜得出来的
- 服务端有尝试限流（同一来源 10 次/分钟），暴力猜要几个月
- 可以自己改，也可以点刷新换一个
- **清空密码 = 拒绝所有来电**。不是"免密码"，是"谁都不许进"

> **警告**：开了无人值守，这台机器就处于"知道密码就能进"的状态。用完请把开关关掉。不要把密码和配对码一起发到有外人的群里。

## 9. 连不上：按症状查

先看主界面底部的**运行日志**，它会说找到几台、连的哪个地址、卡在哪一步。日志比猜快得多。

| 症状 | 最可能的原因 | 怎么办 |
|---|---|---|
| 列表里一台都没有 | 两台不在同一个网络 | 用配对码；或者两端装 Tailscale |
| 列表空，且日志说"找不到 tailscale" | 没装 Tailscale，或没登录 | 装并登录同一账号；局域网内不影响 |
| 列表有名字，点了没反应 | 对方 App 没停在主界面 / 已退出 | 让对方重新打开，停在主界面 |
| 提示"连接超时" | 8787 端口不通 | 对方防火墙放行；`Test-NetConnection 对方IP -Port 8787` 验证 |
| 提示"密码错误" | 密码改过了 | 让对方重新复制配对码 |
| 提示"等一分钟" | 触发限流（10 次/60 秒） | 等一分钟再试 |
| 连上了，但**黑屏** | macOS 屏幕录制权限没给 | 见 3.4，给完**退出重开** |
| 有画面，但**点不动** | macOS 辅助功能没给；或对方是 Windows 且窗口以管理员运行 | 见 3.4；Windows 上让 RemoteDesk 也以管理员运行 |
| 画面卡成几帧 | 走了中继 / 网络差 | 看延迟指标；换 30 fps；靠近路由器 |
| 手机连不上，电脑之间正常 | 手机用的是 4G/5G，且电脑端状态条是橙色「只能在同一个 Wi-Fi 里连」 | 电脑装 Tailscale 并登录，手机装 Tailscale 登同一账号，然后**用配对码连**（手机不会自动发现跨网的电脑） |
| 手机列表里看不到那台电脑，但配对码能连上 | 安卓读不到 Tailscale 的节点列表（那是另一个 App 的进程） | 正常现象。跨网就用配对码，能连 |
| 手机一直转圈停不下来 | 电脑端没响应（程序关了 / 没人点接受） | 点屏幕中间「停止等待」→ 回列表换一台；25 秒也会自己判失败 |
| macOS 提示"已损坏" | Gatekeeper 隔离属性 | 跑 3.1 里那行 `xattr` 命令 |
| 双击 `.command` / `.cmd` 一闪就没 | 脚本提前退出 | 手动在终端/PowerShell 里跑，看完整报错 |
| 提示"端口 8787 已被占用" | 另有一份程序或旧 node 服务占着 | 关掉多余的那份；不影响被连接，但对方可能找不到你 |
| 安卓装不上 | 不是 arm64，或系统低于 7.0 | 换台机器；或用电脑端 |
| 打中文没反应 | 输入通道传按键不传文本 | 在被控端切输入法；或走剪贴板 |
| 粘贴没过去 | 内容在连接前复制的 / 超过 160 KB / 不是纯文本 | 点「推送剪贴板」；缩小内容；只传文本 |
| 用一会儿就断 | 网络切换、休眠、锁屏 | 重新连一次（这一版不会自动重连） |

**网络层先自证**：在操作那台上测对方端口，通了才轮到怀疑软件。

```
Windows:  Test-NetConnection 192.168.1.20 -Port 8787
macOS:    nc -vz 192.168.1.20 8787
```

看到 `succeeded` / `succeeded!` 才算通。不通就是网络或防火墙的事。

**路由器「AP 隔离」**：访客网络常见，开了以后同一 Wi-Fi 下的设备互相看不见。表现就是"明明同一个网，列表空的"。换主网络，或用 Tailscale。

## 10. 安全须知

| 事项 | 说明 |
|---|---|
| 传输加密 | 画面和输入走 WebRTC，DTLS-SRTP 端到端加密；信令只转发不解析 |
| 密码 | 服务端不保存、不校验，只转发。密码错了是被控端拒的 |
| 配对码 | **含明文密码**。发给谁，谁就能连。发完记得换密码 |
| `ws://` 是明文 | 只在可信局域网里用。跨公网必须 `wss://` 或套 Tailscale |
| 8787 不要暴露公网 | 没有账号体系，暴露等于把门开着 |
| 无人值守 | 知道密码就能进。不用时关掉开关 |
| 剪贴板 | 同步是双向的，你在对方机器上复制的东西也会回到你这边 |

## 11. 卸载与文件位置

**macOS**

1. 退出 RemoteDesk（菜单栏 → 退出，不是只关窗口）
2. 把「应用程序」里的 RemoteDesk 拖进废纸篓
3. 想清干净，再删这两处：
   - `~/Library/Logs/RemoteDesk/`
   - `~/Library/Preferences/` 下带 `remotedesk` 的 plist 文件
4. 系统设置 → 隐私与安全性 → 屏幕录制 / 辅助功能，把 RemoteDesk 的条目点「−」移除

**Windows**

1. 退出程序
2. 删除解压出来的整个文件夹（绿色版，不写注册表）
3. 删除 `%LOCALAPPDATA%\RemoteDesk\`
4. 防火墙规则如果加过，删掉：
   `控制面板 → Windows Defender 防火墙 → 允许应用通过防火墙 → 找到 remotedesk → 删除`

**Android**

设置 → 应用 → RemoteDesk → 卸载。没有后台服务残留。

**日志在哪**（排障时把它们发出来，比描述现象有用）

| 平台 | 路径 |
|---|---|
| macOS | `~/Library/Logs/RemoteDesk/app-YYYY-MM-DD.log` |
| Windows | `%LOCALAPPDATA%\RemoteDesk\logs\app-YYYY-MM-DD.log` |
| 界面入口 | 「更多设置」最下面「打开日志目录」 |

日志按天分文件，里面记了：注册成功与否、采集源选了哪个、收到几条轨道、ICE 是否连上、被拒的原因。**"连不上"和"连上了但被拒"是两件不同的事**，日志能分清。

## 12. 附录

### A. 术语表

| 词 | 意思 |
|---|---|
| 被控端 / 主机 | 屏幕被看、被操作的那台 |
| 主控端 | 看着画面动手的那台 |
| 配对码 | `RDSK1 地址:端口 设备名 密码` 一行字，复制粘贴即可连接 |
| 设备名 / ID | 每台机器启动时生成的名字，默认取主机名，可改。握手时用它认人 |
| 信令 | 建立连接前的"打招呼"，只转发，不碰画面 |
| 中继 / TURN | 两端实在打不通时，由第三方转发画面（会慢）。默认不用 |
| Tailscale | 把几台机器组成一个虚拟局域网的软件，地址是 `100.x.x.x` |
| 8787 | 每台机器自己的握手端口。防火墙要放行 |
| 8789 | 局域网自动发现的 UDP 广播端口 |

### B. 一页速查

**装完先做**：macOS 给「屏幕录制」+「辅助功能」→ 退出重开。

**同一个 Wi-Fi**：都打开 → 列表点对方名字 → 对方点「接受并共享屏幕」。

**不在同一个网**：两端装 Tailscale 登同一账号 → 复制配对码发过去 → 粘进框里点「连」。

**先看最上面那条状态条**：绿「出门也能连」= 什么都能连，发配对码就行；橙「只能在同一个 Wi-Fi 里连」= 点右边「怎么连」，照着三步装 Tailscale。

**手机在外面**：手机只有局域网发现这一个通道，跨网必须粘配对码（照样能连，只是不自动出现在列表里）。

**多台设备同时看一台**：被控端直接接受，不踢前一个。一行「N 台设备正在看」可逐个「断开」；多人同时动鼠标会互相抢，留一个就好。

**只知道 IP**：手动连 → 填对方名字 + 密码 + `192.168.1.20`（端口默认 8787）。

**连不上想换一台**：手机屏幕中间有「停止等待 / 回到电脑列表」，点了就能换，不用退出 App。

**黑屏**：屏幕录制权限。**点不动**：辅助功能权限。**列表空**：不在同一个网。

**打不了中文**：在对方机器上切输入法，或用剪贴板。

**出事看日志**：`~/Library/Logs/RemoteDesk/`（Mac）· `%LOCALAPPDATA%\RemoteDesk\logs\`（Win）。

这一页可以单独打印出来，贴在工位上。真出事的时候，先照着最后一行的顺序看：列表空 → 网络；黑屏 → 权限；点不动 → 权限；打不出中文 → 输入法；还是不行 → 发日志。
