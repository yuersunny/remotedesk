# 手机端 Tailscale 设置说明

**RemoteDesk 跨网连接配套** · 安卓手机 · 最后核对 2026-11-13

手机用 4G/5G、或人在外面连公司/家里的电脑时，配对码里那串 `100.x.y.z` 是 Tailscale 的私有地址，公网路由不到它。**手机要装 Tailscale、登录和电脑同一个账号、并把开关打开**，三个条件缺一个都拨不通。这份说明只讲手机这一步；电脑端怎么装见《使用说明书》4.8，电脑端状态条怎么看见 4.4。

---

## 1. 先判断要不要装

| 场景                         | 要不要装 Tailscale           |
| -------------------------- | ------------------------ |
| 手机和电脑连的是同一个 Wi-Fi          | 不用，直接点列表里的电脑             |
| 手机用 4G/5G、或人在外面            | **要装**，而且电脑那头也要装、要登同一个账号 |
| 电脑端状态条是橙色「只能在同一个 Wi-Fi 里连」 | 先在电脑端装好、点「重新检测」，再来做手机这步  |

> **提示**：手机装了 Tailscale，RemoteDesk 的电脑列表里也不会自动多出跨网的电脑——安卓读不到别的 App 的节点列表，这是系统限制。跨网一律用配对码连，能连上。

## 2. 装 App

要求：**Android 8.0 或更高**。

| 渠道          | 从哪拿                                                        | 适合                    |
| ----------- | ---------------------------------------------------------- | --------------------- |
| Google Play | `tailscale.com/download/android` 页面里的 Play 链接              | 手机有 Play 商店，最省事，能自动更新 |
| 官方 APK      | `https://pkgs.tailscale.com/stable/` 页面 Android 一节的 `.apk` | **无 Play 服务的手机用这个**   |
| F-Droid     | F-Droid 里搜 Tailscale                                       | 社区独立编译，版本通常滞后         |

官方 APK 页面里的文件名形如 `tailscale-android-universal-1.xx.x.apk`，下载后点安装，系统问「允许未知来源」时只对这一次放行即可。

> **警告**：网上教程常写的 `.../stable/tailscale-latest.apk` 在 2026-11-13 实测已 **404**，别照抄。只从 `tailscale.com` 或 `pkgs.tailscale.com` 取包，不要装来路不明的 APK——这是要拿 VPN 权限的程序。

> **注意**：防爆手机、企业管控机型可能禁用「未知来源安装」或禁止 VPN 类应用。装不上先找设备管理员，不要为了装它去刷机或绕过管控。

## 3. 首次设置（照着点）

1. 打开 Tailscale，点 **Get Started**。
2. 系统弹「允许 Tailscale 建立 VPN 连接」→ **必须点允许**。这一步拒绝了，后面就算显示登录成功也进不了网络。
3. 推送通知的提示可以允许（用来提醒密钥快过期），不影响连接。
4. 点 **Sign in with Google**，或 **Sign in with other** 选其他账号（Microsoft / GitHub 等）。**必须和电脑端 Tailscale 用同一个账号**——两个不同邮箱就是两个互不相通的网络。
5. 回到主页，把连接开关打开，直到界面显示 **Connected / 已连接**，并能看到自己的 `100.x.y.z` 和那台电脑的设备名。

> **注意**：授权页打不开时，先在电脑浏览器里登一次同一个账号、确认能进管理控制台，再回手机换一个身份提供方重试。账号本身就登不进去的话，手机这步做不下去，别在开关上反复试。

## 4. 三项自检（30 秒）

| 检查    | 怎么做                      | 不对意味着什么           |
| ----- | ------------------------ | ----------------- |
| 开关    | Tailscale 主页显示 Connected | 装了没开，等于没装         |
| 账号    | 手机和电脑 Tailscale 里显示的账    | 登了两个网络，互相看不见      |
| 能看见对方 | 手机 Tailscale 设备列表里有那台电脑  | 电脑端没装 / 没登录 / 已掉线 |

### 用管理后台确认（最硬的证据）

在电脑浏览器打开 `https://login.tailscale.com/admin/machines`，能看到一张设备表，
每行有机器名、账号、`100.x.y.z` 地址、版本和 LAST SEEN。**这张表是注册记录，
不是实时在线名单**——设备「列在里面」不等于「现在连着」。

| LAST SEEN 显示        | 意思                       |
| ------------------- | ------------------------ |
| 绿点 + `Connected`    | 这台设备当前的隧道是通的            |
| 灰点 + 一个日期时间        | **现在不在线**，那个时间是最后一次上线   |
| 表里根本没有这台设备         | 没装、没登录，或登的是另一个账号        |

现场排查时见过典型一例：表里四台设备账号都一致，要连的那台电脑是绿点
`Connected`，而 Android 那台却是灰点、停在两天前。**电脑是好的，防火墙和配对码
都不用动**——问题只是手机上的 Tailscale 没开。把手机开关打开，刷新页面看到那行
变绿，链路就通了。反过来说，如果电脑那行是灰点，先去电脑上开 Tailscale，
手机这头怎么折腾都没用。

顺手核对三点：账号邮箱一致、版本接近、目标电脑的地址与配对码里那段
`100.x.y.z` 一致。版本号旁边的 ↑ 只是提示可升级，不影响连接。
配对码里的设备名是 RemoteDesk 自己的标识，跟后台的机器名不要求一致；
最后一段是口令，电脑端换过就要用新的。

## 5. 回到 RemoteDesk

1. 电脑上打开 RemoteDesk，复制「这台电脑」卡片上的配对码，用微信发到手机。
2. 手机粘进配对码框，点「连接」。粘进去之后，输入框下面会直接写出这行地址是什么、还差哪一步。
3. 想先验通路：手机浏览器打开 `http://100.x.y.z:8787/health`（把 `100.x.y.z` 换成配对码里那段地址）。

| `/health` 结果 | 说明 | 下一步 |
| ------------ | ---- | ------------------------------------- |
| 能打开 | 链路通了 | 回 RemoteDesk 点连接；还连不上就核对配对码末尾的口令有没有改过 |
| **打不开** | 手机 Tailscale 没连上，或电脑防火墙挡了 8787 | 先按第 4 节确认手机那行是绿点 `Connected`；再看电脑端入站规则有没有同时勾「专用」和「公用」 |
| 能打开，RemoteDesk 仍连不上 | 跟网络无关 | 核对口令、确认电脑端 RemoteDesk 开着，展开运行日志看报错 |

## 6. 连不上的常见原因

| 症状                            | 最可能的原因                | 怎么办                                       |
| ----------------------------- | --------------------- | ----------------------------------------- |
| 管理后台里手机那行是灰点、停在几天前 | 手机 Tailscale 没开 / 被省电杀掉 / 密钥到期 | 打开 App 拨到 Connected；顺手把电池优化设为「无限制」 |
| 手机显示 Connected，`/health` 仍打不开 | Windows 防火墙只放行了「专用网络」 | 入站规则补勾「公用网络」；再确认电脑端 RemoteDesk 开着         |
| 手机列表里看不到那台电脑                  | 正常现象（见第 1 节）          | 用配对码连，不要用列表                               |
| 配对码粘好了，按钮灰 / 一直转圈             | 1.0.8 在拨号失败后不会自动复位    | 退出 App 重开；修复已提交仓库，下一次发版带上                 |
| 用着用着突然断                       | 系统省电把 VPN 杀了          | 设置 → 应用 → Tailscale → 电池 → 设为「无限制」        |
| 过一阵子所有设备都要求重新登录               | 设备密钥到期                | 管理控制台 Machines → 该设备 → Disable key expiry |
| 手机同时开着别的 VPN / 私人 DNS         | 安卓同一时间只允许一个 VPN       | 关掉另一个再连                                   |

## 7. 安全提醒

- 配对码里带着连接口令，**只发给要用的人，别发群里**；用完了可以在电脑端换一个新的。
- 控制台里的 **Exit Node（出口节点）** 和 **Subnet Router（子网路由）** 都不要开：开了会把手机的全部流量或整个内网暴露给这个虚拟网络，RemoteDesk 用不上。
- Tailscale 只负责「把路打通」，RemoteDesk 的画面仍是两端直连并加密。
- 每台手机都要单独装、单独登录；换手机要重做一遍。
